# 1. Information We Collect

The system may collect the following categories of information:

## 1.1 Device & Telemetry Data

The Project may collect operational telemetry from connected IoT devices, including:

* Voltage measurements
* Current measurements
* Power consumption
* Power factor
* Frequency
* Harmonic distortion (THD)
* Load signatures used for NILM processing
* Device uptime and diagnostic logs
* Edge inference outputs

Telemetry is primarily generated by embedded microcontrollers and edge devices.

# 2. How We Use Information

Collected information may be used to:

* Operate the smart metering system
* Perform Non-Intrusive Load Monitoring (NILM)
* Analyze electrical and power quality behavior
* Monitor system health and device status
* Enable real-time alerts and protection mechanisms
* Improve research and development activities
* Visualize telemetry on dashboards
* Maintain system security and integrity

We do **not** sell or commercially trade personal data.

---

# 3. Edge Processing & Cloud Architecture

This Project follows an **edge-intelligent architecture**.

Where possible:

* NILM inference and protection logic are executed locally on embedded devices
* Only compressed or semantic telemetry is transmitted to the cloud
* Critical actuation decisions are performed locally without cloud dependency

Cloud services may be provided through:

* Microsoft via [Microsoft Azure](https://azure.microsoft.com?utm_source=chatgpt.com)
* Azure IoT Hub
* Azure Storage
* Azure App Services
* Azure Monitor

Data processed through Azure services is subject to Microsoft’s infrastructure and privacy practices.
